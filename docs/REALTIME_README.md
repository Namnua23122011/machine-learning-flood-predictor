# โหมดข้อมูล API และกำหนดเอง

รันจาก PowerShell:

```powershell
cd C:\mlfloodpredicting
.\myenv.venv\Scripts\python.exe -m api.api
```

เปิด http://localhost:8000 แล้วเลือก **ข้อมูลเรียลไทม์ / API** หรือ **กำหนดเอง**
ถ้าเซิร์ฟเวอร์ทำงานอยู่ กด Ctrl+C แล้วเริ่มใหม่ กด Ctrl+F5 ใน Chrome เพื่อโหลดหน้าใหม่

## สิ่งที่เชื่อมต่อแล้ว

- GET /api/realtime ดึง Open-Meteo สำหรับพิกัดเมืองเชียงใหม่ 18.7883, 98.9853
- รีเฟรชทุก 5 นาทีขณะที่เลือกโหมด API; เซิร์ฟเวอร์แคชผลสำเร็จ 5 นาที
- ค่าเดือน ฝนรายวัน และฝนสะสม 7 วัน มาจาก API จริง
- ฝนเป็น **ค่าประมาณจากแบบจำลองอากาศ** ของวันล่าสุดที่จบแล้ว ไม่ใช่สถานีวัดสด
- ฝนสะสม 7 วันไม่รวมวันเป้าหมาย เพื่อให้ตรงกับสูตรในโน้ตบุ๊ก
- ระดับน้ำปิง ฝนต้นน้ำ เขื่อนแม่งัด ดัชนีความชื้นดิน และพายุ ยังไม่มีแหล่งที่เชื่อมต่อและยืนยันความหมายตรงกับโมเดล
- ถ้าข้อมูลไม่ครบ จะไม่ทำนายอัตโนมัติ กด **นำไปกรอกต่อเอง** แล้วเติมข้อมูลของช่วงวันเดียวกัน
- ไม่มีการเติมศูนย์ การสุ่มค่า หรือการใช้ข้อมูลเก่าแทนเมื่อ API ล้มเหลว
- ปุ่มกำหนดเองเก็บค่าที่กรอกไว้ระหว่างสลับโหมด

โมเดลปัจจุบันฝึกด้วยข้อมูลจำลองและสร้างป้าย flood จาก ping_level >= 3.7
จึงเป็นระบบสาธิตการเชื่อมต่อ ไม่ใช่โมเดลพยากรณ์ล่วงหน้าที่ตรวจสอบกับเหตุการณ์จริง
ความชื้นดินในโน้ตบุ๊กเป็นดัชนีจำลอง 0–1 ไม่ใช่ volumetric soil moisture จาก API อากาศ
จึงไม่แปลงหรือแทนค่ากันโดยอัตโนมัติ

อ้างอิง: https://open-meteo.com/en/docs (daily rain_sum, past_days, timezone)
ข้อมูล Open-Meteo มีเงื่อนไขการใช้งานและ attribution ตามผู้ให้บริการ

## ต่อ provider เพิ่มเติมในอนาคต

FLOOD_DATA_URL เป็น URL ของ **adapter ที่จัดรูปแบบแล้ว** ไม่ใช่การรองรับ URL ThaiWater ทุกรูปแบบโดยตรง
ต้องตรวจสถานี หน่วย วันของฝน เกณฑ์พายุ และการนิยามความชื้นก่อนทำ adapter
ค่าดัชนี soil_moisture ต้องผ่านการกำหนดวิธีเทียบกับข้อมูลฝึกก่อนนำมาใช้

```powershell
$env:FLOOD_DATA_URL = 'https://your-provider.example/normalized-flood-inputs'
# ตั้ง FLOOD_DATA_TOKEN ใน environment เฉพาะเมื่อ provider ต้องการ Bearer token
```

provider ต้องส่ง JSON รูปแบบนี้สำหรับทุกตัวแปรที่มี:

```json
{
  "fields": {
    "ping_level": {
      "value": 2.1,
      "unit": "m",
      "observed_at": "2026-09-07T10:00:00+07:00",
      "source": "ชื่อสถานีและผู้ให้บริการที่ตรวจสอบแล้ว"
    }
  }
}
```

ตัวอย่าง timestamp ไม่ใช่ข้อมูลสด ต้องใช้เวลาตรวจวัดจริงล่าสุด
รับข้อมูลไม่เกิน 1 ชั่วโมงและเวลาในอนาคตไม่เกิน 5 นาที
เมื่อครบทุกช่องจะคำนวณผลให้อัตโนมัติ; ข้อมูลเก่าหรือหน่วยผิดจะถูกนับเป็นช่องที่ขาด

| field | unit |
|---|---|
| month | month |
| rainfall_24h | mm |
| rainfall_7day | mm |
| upstream_rain | mm |
| ping_level | m |
| mae_ngat_storage | % |
| soil_moisture | index_0_1 |
| typhoon_active | 0_or_1 |

ยกเลิก provider ที่ตั้งไว้เพื่อกลับไปใช้ Open-Meteo:
```powershell
Remove-Item Env:FLOOD_DATA_URL -ErrorAction SilentlyContinue
```

ไฟล์โมเดลใน models ไม่ถูกแก้ไข
